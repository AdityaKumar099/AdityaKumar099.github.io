## 🚀 How to View Locally

No setup needed. Just:

1. Download or clone this repository
2. Open `index.html` in any web browser

That's it — the site works completely offline too.

---

## ✏️ How to Customize

Open `index.html` in any text editor (Notepad, VS Code, etc.) and update:

| What to change | Where to find it |
|---|---|
| Your name | Search for `Alex Carter` |
| Your tagline | Search for `Student & Aspiring Developer` |
| About Me text | Look for the `<section id="about">` block |
| Skills & levels | Look for the `<section id="skills">` block |
| Your projects | Look for the `<section id="projects">` block |
| Email / social links | Look for the `<section id="contact">` block |

## 🛠️ Built With

- **HTML5** — Page structure and content
- **CSS3** — Styling, animations, dark theme, responsive layout
- **JavaScript (Vanilla)** — Mobile menu, scroll effects, reveal animations
- **Google Fonts** — Syne + Space Mono typefaces

No libraries, no npm, no build tools required.

## ☁️ Hosting

This site is hosted for free using **GitHub Pages**.

To host your own copy:
1. Fork or upload these files to a GitHub repository named `your-username.github.io`
2. Go to **Settings → Pages → Branch → main → Save**
3. Visit `https://your-username.github.io` after 1–2 minutes
